## 5. 发布成功后的生产 PyPI 验证

只有 workflow 成功后，执行：

python3 - <<'PY'
from urllib.request import urlopen
import json

with urlopen("https://pypi.org/pypi/mavctl/0.2.0/json", timeout=30) as response:
    data = json.load(response)

print("name:", data["info"]["name"])
print("version:", data["info"]["version"])
print("files:")
for item in data["urls"]:
    print("-", item["filename"], item["packagetype"], item["url"])
PY

然后在一个全新环境中安装正式 PyPI 版本：

rm -rf /tmp/mavctl-pypi-smoke
uv venv /tmp/mavctl-pypi-smoke

VIRTUAL_ENV=/tmp/mavctl-pypi-smoke \
  uv pip install \
  --index-url https://pypi.org/simple/ \
  mavctl==0.2.0

/tmp/mavctl-pypi-smoke/bin/mavctl --help
/tmp/mavctl-pypi-smoke/bin/mavctl daemon --help

再验证不是本地源码：

Release notes 内容使用以下 Markdown：

mavctl 0.2.0
First public release of mavctl: a headless, agent-first MAVLink
ground-control CLI for ArduPilot-first workflows.

Highlights
Persistent daemon that owns the MAVLink connection and caches vehicle state.
Structured CLI for status, telemetry, arm, disarm, mode,
takeoff, land, and rtl.
Agent-friendly JSON output, stable exit-code contract, structured guard
reasons and hints.
Safety controls: --confirm, --dry-run, --wait, idempotent commands,
takeoff altitude limits, and positive ground evidence for ordinary disarm.
No force-arm path. disarm --force is emergency motor stop only.
MAVLink transaction safety: serialized dangerous commands, ACK source
validation, target locking, late-ACK quarantine, and link-loss awareness.
Included portable Agent Skill v1 under skills/mavctl-flight/.
Install
Bash

uv tool install mavctl

# or run once:
uvx mavctl --help

# or:
pipx install mavctl
Quickstart
Start with ArduPilot SITL, then:

Bash

mavctl daemon start --connect udp:127.0.0.1:14550
mavctl status --json
See the README and
SITL acceptance guide.

Safety
This release is validated against ArduPilot SITL. It is not presented as
production-ready software for real aircraft. Validate workflows in simulation
before any real-vehicle use.

Verification
178 non-SITL tests
3 ArduPilot SITL integration tests
Published to PyPI through GitHub Actions OIDC Trusted Publishing

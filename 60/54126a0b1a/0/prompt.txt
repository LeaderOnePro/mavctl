## SKILL.md 必须精炼，包含

1. name 和 description：
   明确说明在用户要求控制 MAVLink / ArduPilot vehicle 或 SITL、
   执行起飞、降落、RTL、模式切换时使用。

2. 环境/连接前置流程：
   - daemon status；
   - daemon 未运行时怎样启动；
   - status --json 检查 connected、heartbeat、gps；
   - 不要把 SITL 启动命令硬编码为唯一方式，但可以说明默认 endpoint
     udp:127.0.0.1:14550。

3. 标准起飞工作流：
   - mavctl mode GUIDED --confirm --wait
   - mavctl arm --confirm
   - 轮询 mavctl status --json，直到 armed=true
   - mavctl takeoff --alt <m> --confirm --wait --timeout <s>
   - 起飞中不要发另一个危险命令；status / telemetry 可查询。

4. 标准结束工作流：
   - 正常优先 rtl --confirm --wait；
   - 需要原地落地则 land --confirm --wait；
   - 不要将 disarm 作为正常降落方式；
   - disarm --force 是 emergency motor stop，空中可能坠机。

5. 安全和退出码：
   - 所有状态改变命令均需 --confirm；
   - 推荐先 --dry-run；
   - exit 4：链路失去或 heartbeat 过期，停止进一步控制、排查链路；
   - exit 5：guard 拒绝，读取 JSON detail.reason 和 hint；
   - exit 6：飞控 NACK/ACK timeout/wait timeout，查询 status 再决定；
   - 不存在 arm --force，禁止试图绕过 pre-arm checks；
   - landed_state 可能为 n/a，谨慎使用 disarm。

6. 异步/观察原则：
   - --wait 等目标状态；
   - arm ACK 可能早于 heartbeat armed=true，必须轮询确认；
   - 使用 status --json 作为当前世界状态来源；
   - daemon / adapter 已串行化危险操作，但 agent 仍不应并行发多个危险命令。

7. 说明当前范围：
   - 目前支持 status、telemetry、arm、disarm、mode、takeoff、land、rtl；
   - mission upload/download、parameter editing、geofence 等尚未实现；
   - 不要猜测或模拟不存在的命令。

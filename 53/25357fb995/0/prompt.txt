## 1. README.md

如果 README.md 不存在，创建它；如果存在，重写/完善为项目的主入口文档。

README 必须包含：

### 标题与一句话定位

例如：

# mavctl

> Headless, agent-first MAVLink ground-control CLI for ArduPilot vehicles.

同时清楚写明：

- ArduPilot-first；
- 面向 humans 和 AI coding agents；
- 基于 daemon + CLI；
- 当前主要在 ArduPilot SITL 上验证；
- 不要宣称已支持所有 MAVLink vehicle 或已适合生产真机飞行。

### Why mavctl

简短说明：

- GUI GCS（Mission Planner / QGroundControl）适合人工操控；
- mavctl 是给 shell、脚本和 agent 的结构化接口；
- daemon 保持 MAVLink 链路与状态；
- CLI 输出 JSON、明确 exit code、安全护栏；
- 不内置 LLM，而是能被 Claude Code / Codex / OpenClaw 等调用。

### Current capabilities

准确列出已实现：

```bash
mavctl daemon start|stop|status
mavctl status
mavctl telemetry
mavctl arm
mavctl disarm
mavctl mode <MODE>
mavctl takeoff --alt <metres>
mavctl land
mavctl rtl
```

写出：

- JSON: `--json`
- confirmation: `--confirm`
- preview: `--dry-run`
- wait: `--wait --timeout`
- idempotent behavior
- MAVLink command transaction safety

并写清当前未实现：

```text
Mission upload/download/start
Parameters
Geofence
Log download / analysis
Firmware flashing
Multi-vehicle orchestration
```

不要写成 roadmap 承诺，只说 current scope。

### Quickstart with ArduPilot SITL

提供 macOS/Linux 风格的最小真实步骤：

```bash
# In one terminal: start existing ArduPilot SITL
sim_vehicle.py -v ArduCopter --out udp:127.0.0.1:14550

# In another terminal: install/run mavctl from source
uv sync
uv run mavctl daemon start --connect udp:127.0.0.1:14550
uv run mavctl status --json
```

再给安全起飞并 RTL 的完整 sequence：

```bash
uv run mavctl mode GUIDED --confirm --wait
uv run mavctl arm --confirm
# Poll status --json until armed=true
uv run mavctl takeoff --alt 10 --confirm --wait --timeout 45
uv run mavctl rtl --confirm --wait --timeout 120
uv run mavctl daemon stop
```

必须强调：
- SITL first；
- 不要直接将 agent 流程用于真实飞行器；
- arm ACK 可能早于 heartbeat armed=true；
- 正常结束优先 RTL/land，不要用 disarm；
- `disarm --force` 是紧急停桨；
- 不存在 `arm --force`。

### Safety model

摘要链接 / 说明：

- daemon owns vehicle link;
- dangerous commands require confirm;
- dry run;
- link loss exit 4;
- guard rejection exit 5;
- vehicle NACK/timeout exit 6;
- no force arm;
- positive ground evidence before ordinary disarm;
- status can contain cached data after link loss.
